# Proposal

## Why

Тренажёр вычитает задержку по правилу записи REAPER — по задержке, о которой
сообщает драйвер, и ручным поправкам REAPER. Драйвер сообщает задержку не
полностью и не всегда точно: ошибка бывает больше миллисекунды и в любую
сторону, а задержку инструмента MIDI — опрос клавиш и датчиков, USB, кабель —
не учитывает никто. Гитарист видит отклонения, сдвинутые на эту ошибку, и
поправить её может только вручную, замерив петлю и вписав поправку в
настройки REAPER.

## What Changes

- **Калибровка задержки — внутри калибровки.** У входа звука «Calibrate…»
  открывает экран выбора: Levels — нынешняя калибровка уровней, Latency —
  калибровка задержки звука. У входа MIDI появляется кнопка «Calibrate…»; она
  сразу открывает калибровку задержки MIDI.
- **Калибровка задержки звука — петлёй через метроном.** Гитарист втыкает
  кабель с выхода, где звучит метроном, во вход гитары. Start глушит дорожки
  проекта, кроме мастер-дорожки, и запускает воспроизведение с метрономом;
  тренажёр меряет отклонение 12 кликов — после первого — по правилу записи
  REAPER и останавливает транспорт. Медиана отклонений — поправка к Input
  manual offset. Глушение дорожек и метроном после калибровки возвращаются,
  в конце панель просит подключить гитару.
- **Калибровка задержки MIDI — по удару, который слышит звуковой вход.** При
  остановленном транспорте гитарист бьёт 16 раз; звуковой вход (микрофон у
  пэда, разветвлённый кабель датчика, звукосниматель MIDI-гитары) слышит удар,
  вход MIDI даёт ноту. Медиана разниц «нота MIDI − удар», обе по правилам
  записи REAPER, — задержка MIDI X: к Output manual offset прибавляется X, из
  Input manual offset вычитается X, чтобы звук не сдвинулся. Поправка MIDI
  одна на все устройства MIDI.
- **Итог — инструкция и Apply to REAPER.** Итог по шагам говорит, какие ручные
  поправки поставить в Preferences → Audio → Recording и на какие значения;
  кнопка Apply to REAPER делает то же автоматически: пишет поправки в
  настройки REAPER и сохраняет их. Тренажёр по-прежнему считает задержку по
  правилу записи REAPER, поэтому новые поправки сдвигают и его отклонения, и
  запись в REAPER.
- **Плохие замеры.** Клики с разбросом больше 1 мс — поправка не предлагается,
  «Apply … anyway» всё же ставит её. Без клика 5 с после Start и без ноты MIDI
  15 с калибровка обрывается с подсказкой. Нота без удара во входе в пределах
  100 мс в замер не идёт.
- **Руководство.** `docs/usage.md`: калибровка задержки звука и MIDI, чем
  услышать удар без микрофона, как вписать известную задержку MIDI вручную.
- Образец вида и хода — `mockup.html` в этом изменении (утверждён); факты
  разведки — `findings.md`.

Вне scope:

- калибровка MIDI без кабеля, по ответному тону (как Tap to Tone в
  OboeTester), — отдельное изменение `add-midi-latency-tap-to-tone`;
- своя поправка задержки у тренажёра в обход настроек REAPER;
- поправка MIDI для каждого устройства отдельно: у REAPER её нет;
- путь клика по воздуху от колонок до уха.

## Capabilities

### New Capabilities

- `latency-calibration`: калибровка задержки звука петлёй через метроном и
  задержки MIDI по удару, услышанному звуковым входом, — ход, что меряется,
  какие ручные поправки REAPER получаются, итог-инструкция и запись поправок
  в настройки REAPER.

### Modified Capabilities

- `input-calibration`: «Calibrate…» открывает выбор калибровки у входа звука и
  калибровку задержки MIDI у входа MIDI; калибровка уровней начинается по
  кнопке Levels.
- `hit-timing`: требования «по правилу записи REAPER» для звука и MIDI больше
  не запрещают калибровку задержки: поправки на задержку тренажёр берёт из
  настроек REAPER, а калибровка задержки их меняет.
- `timing-display`: у входа MIDI строка калибровки остаётся с одной кнопкой
  «Calibrate…».

## Impact

- **`libs/trainer`**: ход калибровок задержки — сбор отклонений кликов, пары
  «удар — нота MIDI», медиана, разброс, вердикт и новые ручные поправки.
  Чистая логика, проверяется тестами без REAPER.
- **`src/`**: связка с REAPER — запуск и остановка воспроизведения, метроном,
  глушение дорожек и его возврат, чтение и запись `adjrecmanlatin` и
  `adjrecmanlat`, время нот MIDI при остановленном транспорте по счёту
  сэмплов хука; `AudioInput` — номер первого сэмпла у куска калибровки и
  канал удара; `window.cpp` и `forms.rc` — экран выбора, панели калибровок
  задержки, список входа удара, Apply to REAPER.
- **Настройки тренажёра**: новых нет. Калибровка меняет только ручные
  поправки REAPER — после согласия пользователя.
- **Документация**: `docs/usage.md`.
