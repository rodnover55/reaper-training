# add-midi-latency-tap-to-tone

Второй способ калибровки задержки MIDI — без кабеля-петли, как тест Tap to Tone в OboeTester. Микрофон слышит удар по пэду или клавише и короткий тон, которым тренажёр отвечает на каждую ноту MIDI в выход метронома (наушники у микрофона); задержка входа одинакова для обоих звуков и сокращается, и разница «тон − удар» за вычетом известной реакции тренажёра даёт задержку MIDI прямо от слышимого клика. Итог, как у калибровки «петля плюс удар» (add-latency-calibration): Output manual offset + X, Input manual offset − X, инструкция и Apply to REAPER. Если удар подаётся без микрофона — разветвлённым кабелем датчика пэда или наушниками вместо микрофона, — тон подаётся кабелем с выхода метронома на второй вход той же карты. Сложность — найти тон поверх звука удара: тон отличимой частоты, поиск сравнением с отправленным сигналом. Решения — память decisions-latency-calibration, факты — findings.md изменения add-latency-calibration (R1: щелчок из хука в выход, R4: время ноты MIDI в счёте хука). Первый шаг — макет, пропозал после его одобрения.
