# Proposal

## Why

Тренажёр слушает только канал звуковой карты, а нота для него — фронт атаки
звука. Клавишник, барабанщик с электронной установкой и гитарист с
MIDI-звукоснимателем играют в REAPER через вход MIDI, и тренажёр их игру не
меряет. По MIDI начало ноты известно точно, без поиска атаки, поэтому такой
вход даёт точное измерение и инструментам без звукового выхода.

## What Changes

- В списке **Input** после каналов звуковой карты — **входы MIDI**, «MIDI:
  имя устройства», как их называет REAPER, с псевдонимом из его настроек.
  Виртуальная MIDI-клавиатура REAPER (Virtual MIDI keyboard) — тоже в списке.
  Петлевых входов REAPER (loopback) в списке нет: в петлю попадает только
  MIDI, рождённый в самом REAPER, а не живая игра. Кнопка **Refresh** справа
  от списка перечитывает входы: устройство, подключённое при открытом окне,
  появляется в списке после её нажатия.
- С входа MIDI нота — сообщение начала ноты (Note On) с ненулевой громкостью
  (velocity) на любом из 16 каналов MIDI. Note Off, контроллеры, педаль и
  pitch bend нот не дают. Тихая нота меряется так же, как громкая.
- **Мёртвое время после ноты MIDI**: первая нота измеряется, и от её времени
  на шкале проекта идёт мёртвое время 40 мс — то же, что у поиска атак звука;
  ноты в нём пропускаются. Нота вне мёртвого времени, позже или раньше него,
  измеряется и начинает своё; если она у того же узла сетки, у узла лишняя
  нота «*». Мёртвое время кончается с концом прохода петли и с остановкой
  транспорта. Настройки мёртвого времени нет.
- **Время ноты — как у записи REAPER**: куда REAPER поставил бы начало ноты
  при записи MIDI с этого входа, с теми поправками на задержку, которые
  REAPER применяет к записи MIDI. Точность — 1 мс относительно записанного
  MIDI-айтема. Задержку кабеля MIDI и USB тренажёр не учитывает, как не
  учитывает её запись; квантование записи дорожки (Input quantize) — тоже:
  меряется сыгранное.
- Значение появляется в окне раньше, чем пройдёт 250 мс после ноты, — то же
  требование, что у звука.
- Вход MIDI должен быть включён в настройках REAPER для записи на дорожки, как
  для обычной записи с него. Выключенный вход помечен в списке «(not
  enabled)», а строка состояния говорит, что его надо включить в настройках
  REAPER. Вход, включённый только для управления (control messages), нот не
  даёт. Отключённое устройство — «selected input is not available», как
  пропавший канал звуковой карты.
- Вход MIDI запоминается по имени устройства: если REAPER дал устройству
  другой номер, тренажёр найдёт его по имени.
- Для входа MIDI нет четвёртой строки настроек — порога тишины (Silence) и
  калибровки (Calibrate…); строки тактов занимают её место. Порог тишины при
  этом сохраняется и вернётся со звуковым входом.
- Строки тактов, режимы, окно попадания, строка состояния, измерение только
  при воспроизведении и записи, count-in и петля — как у звука.
- Образец вида — `mockup.html` в этом изменении.

Вне scope:

- выбор одного канала MIDI и вход «All MIDI inputs»;
- петлевые входы REAPER (loopback);
- порог громкости нот MIDI — аналог порога тишины;
- настройка мёртвого времени;
- поправка на задержку кабеля MIDI, USB и синтезатора;
- два входа сразу — звук и MIDI.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `hit-timing`: новый источник нот — вход MIDI; начало ноты MIDI и мёртвое
  время после неё; время ноты MIDI по правилу записи MIDI REAPER с точностью
  1 мс; вход должен быть включён в REAPER.
- `timing-display`: входы MIDI в списке Input и их пометка; настройки для
  входа MIDI без порога тишины и калибровки; строка состояния о выключенном
  входе MIDI; петлевых входов в списке нет; сохранение входа MIDI по имени;
  задержка показа — и для нот MIDI.
- `input-calibration`: калибровки нет, пока выбран вход MIDI.

## Impact

- **`libs/onset`**: мёртвое время нот MIDI — чистая логика без REAPER с
  тестами.
- **`libs/grid`**: компенсация задержки записи MIDI — по правилу REAPER, с
  тестами.
- **`src/`**: `trainer` — ноты выбранного входа MIDI из истории MIDI-входа
  REAPER, его состояние и компенсация; `settings` — вход MIDI по имени;
  `window.cpp`, `forms.rc` — список входов, скрытая четвёртая строка, строка
  состояния; `debug_actions` — сверка с MIDI-айтемом и ноты без устройства
  для проверок.
- **Звук не меняется**: поиск атак, порог тишины, калибровка и время ноты
  со звукового входа — как в `hit-timing` и `input-calibration`.
- **Настройки**: новый ключ входа MIDI в разделе расширения
  `reaper-extstate.ini`. Прежние версии его не читают и берут сохранённый
  канал звуковой карты.
- **Разведка** (`findings.md`): правило, по которому REAPER кладёт запись
  MIDI на шкалу, найдено и совпадает с записью до 0.25 мс, в том числе для
  нот устройства с отметкой времени. Стоп-условие: если на живой проверке
  место записи MIDI не воспроизводится с точностью 1 мс, работа
  останавливается; путь с большей ошибкой берётся только с одобрения
  пользователя.
- **Документация**: `docs/usage.md` — вход MIDI в разделах «Подготовка»,
  «Окно» и «Игра».
- Версия — 0.7.0.
