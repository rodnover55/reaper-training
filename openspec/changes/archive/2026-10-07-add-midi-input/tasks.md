# Tasks

Образец вида — `mockup.html`. Разведка — `findings.md`; проверки вживую
дописываются туда же. Ноты без устройства MIDI — виртуальная MIDI-клавиатура
REAPER: `StuffMIDIMessage(0, …)` из скрипта ReaScript; ноты с отметкой времени
внутри блока — `snd-virmidi` и `aplaymidi` (design D7). Перед проверками
вживую — прочитать `[reaper_training]` в `reaper-extstate.ini` и после
проверок вернуть ровно эти настройки; ключи `midiins` в `reaper.ini`,
поставленные для проверок, — убрать.

## 1. Мёртвое время MIDI и компенсация — чистые библиотеки

- [x] 1.1 `training/onset/dead_time.hpp` (design D4): `DeadTime` с мёртвым
      временем `Settings{}.deadTimeMs` по времени ноты на шкале проекта в
      секундах, `reset()`, разбор начала ноты — Note On с ненулевой
      громкостью на любом канале. Проверка — `tests/onset_dead_time_test.cpp`
      в `ctest --preset quick`: ноты на 3, 5, 9, 12 мс — измерена нота на
      3 мс; ноты на 0, 15, 30, 45, 55 мс — измерены 0 и 45 мс; нота ровно на
      40 мс — пропущена, на 40.001 мс — измерена; одиночные ноты через 100 мс
      — измерена каждая; нота раньше мёртвого времени — измерена; после
      `reset()` нота — измерена; `0x99 n 1` — начало ноты, `0x90 n 0`,
      `0x80`, `0xB0 64 127` и pitch bend — другие сообщения
- [x] 1.2 `grid::midiCompensation` (design D2) в `libs/grid`. Проверка —
      тесты в `tests/grid_note_time_test.cpp` по таблице R2 `findings.md`:
      буфер 512, выход 1024, 48 кГц, галка — 32.0 мс; выход с поправкой 1504
      — 42.0 мс; без галки — 10.667 мс, без галки с поправкой выхода 480 —
      20.667 мс; буфер 128 — 8.0 и 2.667 мс; буфер 1024 — 64.0 и 21.333 мс

## 3. Вход MIDI в настройках и тренажёре

      сохранённое имя, которого нет, — «selected input is not available»;
