# Spec Delta

## ADDED Requirements

### Requirement: Установщик для каждой системы

Для Windows x64, macOS 12 и новее и Linux x86_64 SHALL быть установщик
расширения. Установщик SHALL класть файл расширения в `UserPlugins` папки
ресурсов найденного REAPER и SHALL создавать `UserPlugins`, если её нет.
Пользователь SHALL NOT указывать путь сам, если REAPER стоит в обычном месте.

#### Scenario: Windows

- **WHEN** на Windows стоит REAPER 7 x64, установленный его установщиком, и
  пользователь запускает установщик расширения
- **THEN** файл расширения лежит в `%APPDATA%\REAPER\UserPlugins`

#### Scenario: macOS

- **WHEN** на macOS в «Программах» стоит REAPER 7, и пользователь открывает
  пакет расширения
- **THEN** файл расширения лежит в
  `~/Library/Application Support/REAPER/UserPlugins`

#### Scenario: Linux, REAPER в ~/opt

- **WHEN** на Linux REAPER 7 поставлен своим сценарием в `~/opt/REAPER`, и
  пользователь запускает установщик расширения
- **THEN** файл расширения лежит в `~/.config/REAPER/UserPlugins`

#### Scenario: Linux, REAPER из Flatpak

- **WHEN** на Linux REAPER стоит из Flathub (`fm.reaper.Reaper`)
- **THEN** файл расширения лежит в
  `~/.var/app/fm.reaper.Reaper/config/REAPER/UserPlugins`

#### Scenario: Папки UserPlugins нет

- **WHEN** REAPER стоит, но ещё ни разу не запускался, и папки ресурсов нет
- **THEN** установщик создаёт папку ресурсов и `UserPlugins` в ней и кладёт
  туда файл расширения

### Requirement: Установка без прав администратора

Установщик SHALL ставить, обновлять и удалять расширение с правами
пользователя, который его запустил, и SHALL NOT запрашивать права
администратора или root. Запуск установщика для Linux от root SHALL
отклоняться без изменений в файлах.

#### Scenario: Обычный пользователь Windows

- **WHEN** пользователь без прав администратора запускает установщик на
  Windows
- **THEN** окно контроля учётных записей (UAC) не появляется, расширение
  ставится

#### Scenario: Пакет на macOS

- **WHEN** пользователь открывает пакет расширения на macOS
- **THEN** установка не спрашивает пароль администратора

#### Scenario: Linux от root

- **WHEN** установщик для Linux запущен через `sudo`
- **THEN** он сообщает, что ставить нужно от своего пользователя, и
  завершается с ошибкой, ничего не поставив

### Requirement: Установщик проверяет REAPER

Установщик SHALL ставить расширение, только если нашёл REAPER, который может
загрузить модуль: на Windows — 64-битный, на Linux и macOS — версии 7 или
новее. REAPER найден, если его программа стоит в обычном для системы месте или
в папке ресурсов REAPER есть `reaper.ini`. Если REAPER нет или он не подходит,
установщик SHALL назвать причину и SHALL NOT менять файлы. Версию, которую
определить нельзя, установщик SHALL считать подходящей.

#### Scenario: REAPER не установлен

- **WHEN** REAPER на компьютере нет, и пользователь запускает установщик
- **THEN** установщик сообщает, что REAPER не найден, и завершается, ничего не
  поставив

#### Scenario: REAPER 6

- **WHEN** на Linux или macOS стоит только REAPER 6
- **THEN** установщик сообщает, что нужен REAPER 7 или новее, и ничего не
  ставит

#### Scenario: 32-битный REAPER на Windows

- **WHEN** на Windows стоит только 32-битный REAPER
- **THEN** установщик сообщает, что нужен 64-битный REAPER, и ничего не ставит

#### Scenario: REAPER в необычном месте

- **WHEN** на macOS `REAPER.app` лежит не в «Программах», но REAPER уже
  запускался, и в `~/Library/Application Support/REAPER` есть `reaper.ini`
- **THEN** установщик ставит расширение в
  `~/Library/Application Support/REAPER/UserPlugins`

### Requirement: Портативный REAPER

Портативный REAPER, который установщик не нашёл, SHALL указываться вручную:
на Windows — выбором папки в установщике, на Linux — ключом `--resource-path`.
В указанной папке SHALL быть `reaper.ini`, иначе установщик SHALL отказывать.

#### Scenario: Портативный REAPER на Linux найден

- **WHEN** REAPER поставлен в `~/opt/REAPER`, и рядом с программой лежит
  `reaper.ini`
- **THEN** файл расширения лежит в `~/opt/REAPER/UserPlugins`

#### Scenario: Портативный REAPER на Windows не найден

- **WHEN** на Windows REAPER не найден, и пользователь запускает установщик
- **THEN** установщик предлагает указать папку портативного REAPER; в папке с
  `reaper.exe` и `reaper.ini` расширение ставится в её `UserPlugins`

#### Scenario: Папка без reaper.ini

- **WHEN** пользователь указал папку, в которой нет `reaper.ini`
- **THEN** установщик сообщает, что это не папка REAPER, и ничего не ставит

### Requirement: Обновление установщиком

Установщик новой версии SHALL заменять файл расширения прошлой версии.
Установщик для Linux SHALL заменять файл так, что запущенный REAPER продолжает
работать, и SHALL сообщать, что REAPER нужно перезапустить.

#### Scenario: Новая версия поверх старой

- **WHEN** стоит расширение 0.3.0, и пользователь запускает установщик 0.4.0
- **THEN** в `UserPlugins` один файл расширения — версии 0.4.0

#### Scenario: REAPER запущен на Linux

- **WHEN** REAPER запущен с расширением, и пользователь запускает установщик
- **THEN** REAPER продолжает работать, файл заменён, установщик просит
  перезапустить REAPER

### Requirement: Удаление расширения

На Windows расширение SHALL удаляться из списка установленных программ
Windows, на Linux — тем же установщиком с ключом `--uninstall`. Удаление SHALL
убирать файл расширения из тех папок, куда его кладёт установка, и SHALL NOT
трогать другие файлы REAPER. На macOS инструкция SHALL говорить, какой файл
удалить.

#### Scenario: Удаление на Windows

- **WHEN** пользователь удаляет reaper-training в «Установке и удалении
  программ»
- **THEN** файла расширения в `UserPlugins` нет, остальные файлы папки
  ресурсов на месте

#### Scenario: Удаление на Linux

- **WHEN** пользователь запускает установщик с ключом `--uninstall`
- **THEN** файла расширения нет в `UserPlugins` найденных REAPER

### Requirement: Без пометки карантина на macOS

Файл расширения, поставленный пакетом на macOS, SHALL NOT нести пометку
карантина, даже если сам пакет скачан из интернета. Инструкция SHALL
говорить, как открыть пакет, не подписанный Apple.

#### Scenario: Пакет скачан браузером

- **WHEN** пакет скачан из Releases браузером, и пользователь его поставил
- **THEN** у файла расширения нет атрибута `com.apple.quarantine`, REAPER
  загружает расширение
