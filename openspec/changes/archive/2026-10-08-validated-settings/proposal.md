# Proposal

## Why

Тренажёр молча прижимает недопустимое значение настройки к ближайшей границе:
Silence −5 становится −10, Offset +45 при допуске 10 — +40, `window_scale_ms=500`
в `reaper-extstate.ini` — 200, неизвестный режим сетки из файла — «четверти».
Пользователь не узнаёт, что вписанное не принято и какие значения допустимы.

## What Changes

- `trainer::Settings` — класс, который проверяет значения в своих сеттерах:
  недопустимое значение отклоняется, и у настройки остаётся прежнее значение.
  `trainer::clamped` уходит.
- Поля Offset, Tolerance и Silence. Недописанное число настроек не меняет.
  Число вне допустимого диапазона не действует и не сохраняется: поле
  обведено красной рамкой, строка состояния вместо обычного текста называет поле,
  вписанное значение, допустимый диапазон и действующее значение. Допустимое
  число сразу действует и сохраняется. Уход фокуса из поля возвращает в него
  действующее значение. Округление смещения и допуска до 0.5 мс остаётся.
- Пока курсор мыши над полем Offset, Tolerance или Silence, у него
  всплывает подсказка с допустимым диапазоном поля при действующих значениях
  остальных настроек.
- Строки `reaper-extstate.ini`, которые сеттеры отклоняют при запуске REAPER, —
  `mode` без режима сетки, `window_scale_ms` вне 10–200, `offset_ms` и
  `tolerance_ms` с окном попадания вне шкалы, `silence_db` вне −90…−10, — не
  принимаются: у настройки действует значение по умолчанию, остальные строки
  принимаются. Сохранённое окно попадания вне шкалы больше не сужается и не
  сдвигается к нулю.
- Не принятые строки файла пишутся в журнал тренажёра при чтении файла и
  называются в строке состояния при открытии окна — до первой правки настроек
  или первого запуска транспорта. Файл переписывается только обычным
  сохранением настроек.
- Ползунки шкалы и калибровка берут допустимый диапазон из настроек и ставят
  только допустимые значения; сообщений у них нет.
- Строка состояния, которая не помещается в окно, — например сообщение о двух
  не принятых строках файла, — обрезается с «...» в конце, а подсказка при
  наведении мыши показывает её полный текст.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `timing-display`: настройки тренажёра — допустимые диапазоны и отказ
  принять недопустимое значение вместо прижатия; подсказка у полей; сообщение
  в строке состояния; строки `reaper-extstate.ini`, которые не принимаются, —
  граница шкалы и сохранённое окно попадания; строка состояния, которая не
  помещается, — с «...» и подсказкой с полным текстом.
- `input-calibration`: порог тишины по итогу калибровки лежит в допустимом
  диапазоне настройки порога тишины.

## Impact

- `libs/trainer` — `Settings` с сеттерами вместо `clamped`; `Calibrator` —
  диапазон порога из настроек; юнит-тесты сеттеров в
  `tests/trainer_settings_test.cpp`.
- `libs/grid` — правка смещения и допуска окна попадания без прижатия к шкале
  (`withOffset`, `withTolerance`, `fitted`); `tests/grid_hit_window_test.cpp`.
- `src/settings.cpp` — чтение `reaper-extstate.ini` через сеттеры, список не
  принятых строк.
- `src/window.cpp` — рамка вокруг поля, сообщение в строке состояния,
  подсказка через `TrackCtl_SetToolTip` по `WM_SETCURSOR`.
- `src/trainer.cpp` — применение настроек без `clamped`, журнал не принятых
  строк.
- `README.md` — раздел о границе шкалы: значение вне 10–200 не принимается;
  раздел «Проверка вживую» — новые команды `live.py`.
- `libs/trainer` — обрезка строки состояния (`fitText`) с юнит-тестами;
  `src/window.cpp` — обрезанная строка состояния и подсказка с полным текстом.
- `tools/live/live.py` — набор текста в поля, клавиши, наведение мыши и снимок
  окна подсказки для проверок вживую.
