# Tasks

Разведка (раздел 3) идёт до настройки детектора на записях и до окна. Её ответы
записываются в `findings.md` и правят design и specs. Если сработало
стоп-условие из `proposal.md`, работа по разделам 4–8 не начинается, а решение
выносится пользователю.

## 5. Сетка и свод ударов

- [x] 5.1 Сделать в `training_grid` время ноты `P + (i / sr - компенсация) * r`
      и заворот в петлю (design D2). Проверка — тесты: при `r` = 1.0 формула
      даёт `P + i / sr - компенсация`; при `r` = 0.8 компенсация 32 мс сдвигает

      перехода, ложится на 11.995
- [x] 5.2 Сделать в `training_grid` поиск ближайшего узла по переводу
      «доли → время» для пяти режимов (design D5). Проверка — тесты: при
      120 BPM узлы шестнадцатых через 125 мс; нота +70 мс от узла уходит к
      следующему с −55 мс; плавная смена темпа; первый узел следующего удара
- [x] 5.3 Сделать свод ударов (design D6): лишняя нота, пропуск по позиции
      транспорта, среднее и разброс без пропусков и лишних, строки только у
      ударов с нотами, последние 8, смена режима со следующего удара.
      Проверка — тесты по сценариям `hit-timing` и `timing-display`: галоп,
      ноты −20 и +4 мс у одного узла, −4/+2/+6/+4 → «+2.0» и «3.7», пауза в
      игре, девятый удар
- [x] 5.4 Сделать модель показа: перевод в реальные мс делением на `r`,
      округление до целых мс со знаком, «0», цвет по показанному числу и
      допуску, «.» и «*», среднее и разброс с одним знаком, «четверти» без
      среднего. Проверка — тесты: −15.3 → «−15»; при допуске 10 «−15»
      красное, «+5» и «+10» зелёные; при `r` = 0.8 разница 8 мс на шкале →
      «+10»
