# Записи для регрессии поиска атаки

Настоящие записи DI-гитары: Quad Cortex по USB, сухой вход, один канал,
48 кГц, PCM 24 бит. Метроном 120 BPM, 4/4 — доля каждые 0.5 с, гитарист играет
четверти. Порог тишины в тренажёре −60 dBFS: при −50 щелчок медиатора на этом
тихом DI порога не проходит.

Времена — от начала файла, в секундах. Настоящая атака — момент удара
медиатора, размечена по подъёму ВЧ-огибающей детектора (ВЧ-фильтр 1 кГц) над её
максимумом за предыдущие 5–25 мс, допуск разметки ±15 мс. Начало файла —
начало потока: звон, который уже звучал, атакой не считается.

Проверяет их `tests/onset_recordings_test.cpp`: каждая размеченная атака
найдена в пределах допуска, лишних нет.

## di_muted_quarters.wav — глушёные ноты

3.9 с, вырезано из тейка с 1.80 по 5.70 с. Каждая нота заглушена до следующей.

Атаки (8): 0.1752, 0.6642, 1.1862, 1.6651, 2.1543, 2.6691, 3.1752, 3.6917.

Щелчок медиатора тихий: ВЧ-огибающая −54…−60 dBFS. Через 25–35 мс после него
разгорается тело ноты, ВЧ −33…−50 dBFS, — это не новая атака. Детектор с
опорой «огибающая 5 мс назад» и мёртвым временем 25 мс давал на каждую ноту
2–3 атаки.

## di_ringing_low_b.wav — незаглушённая низкая си

1.1 с, вырезано из тейка с 26.30 по 27.40 с. Струна си, около 62 Гц, период
16 мс, звенит всё время; удары идут по звучащей струне.

Атаки (2): 0.1249, 0.6382. Клики метронома — 0.200 и 0.700, то есть атаки на
−75 и −62 мс.

Звенящая струна даёт короткий ВЧ-всплеск раз в период. Детектор с опорой
«огибающая 5 мс назад» находил атаку каждые 31 мс, пока звенит струна, — 18 на
этом отрезке; клику 0.700 доставалась ложная атака 0.7005, и окно показывало
«0» вместо −62 мс.

## di_ringing_low_b_long.wav — то же, длиннее

3.0 с, вырезано из того же тейка с 25.30 по 28.30 с. После 2.5 с — тишина.

| Атака | Клик | Отклонение | Подъём ВЧ-огибающей над звоном за 5–25 мс |
|---|---|---|---|
| 0.1586 | 0.200 | −41 мс | +2.9 дБ |
| 0.6502 | 0.700 | −50 мс | +16.5 дБ |
| 1.1249 | 1.200 | −75 мс | +10.1 дБ |
| 1.6382 | 1.700 | −62 мс | +7.3 дБ |
| 2.1381 | 2.200 | −62 мс | +5.7 дБ |

Удар по ещё звенящей струне поднимает пик ВЧ-огибающей над звоном всего на
+2.9 и +5.7 дБ — меньше, чем вдвое. По одному пику его от звона не отличить:
пульсация звона даёт до +2.7 дБ. Отличает его длительность — шум медиатора
держит верх спектра несколько миллисекунд, а звон даёт один всплеск за период.
